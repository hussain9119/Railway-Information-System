HUSSAIN BLOOD BANK — MULTI-PAGE FRONT-END DEMO
================================================
Pages included:
- index.html — Home
- about.html — About
- donate.html — Donate
- request.html — Request Blood
- stock.html — Sample Blood Stock
- gallery.html — Camps & Gallery
- contact.html — Contact

Shared assets:
- css/style.css
- js/main.js
- images/doctor-portrait.png (illustrative generated doctor portrait)

HOW TO OPEN:
1. Extract the ZIP.
2. Open the extracted folder.
3. Double-click index.html.
4. Use the top navigation to open each separate HTML page.

NOTES:
This is a student front-end demonstration only. It has no backend, database, live inventory, donor matching, or emergency support. Stock figures are fictional sample data. The request form only displays a local demo message. Use authorised medical services for real blood donation or urgent medical needs.
Internet is needed for Google Fonts, Lucide icons and remote Unsplash gallery/background photos.
